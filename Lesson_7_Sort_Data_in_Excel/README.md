# 🔃 Sorting Data in Excel

**Sorting** in Excel is used to arrange data in a specific order, such as **A to Z, Z to A, smallest to largest, or largest to smallest**.

---

# 1️⃣ Sort Data Using Excel

There are two common ways to access sorting:

### 📊 Data Tab

```text
Data → Sort & Filter → Sort
```

### 🏠 Home Tab

```text
Home → Sort & Filter
```

---

# 2️⃣ 🔤 Basic Sorting

Excel provides two quick sorting options:

### 🔼 A to Z

Sorts text in **ascending order**.

```text
A → Z
```

For numbers:

```text
Smallest → Largest
```

### 🔽 Z to A

Sorts text in **descending order**.

```text
Z → A
```

For numbers:

```text
Largest → Smallest
```

---

# 3️⃣ 📋 Sorting the Whole Data

When sorting a table, it is important to sort the **complete dataset**, not just one column.

### Steps

1. Select a column that you want to sort.
2. Choose **Sort A to Z** or **Sort Z to A**.
3. Excel may show:

```text
Expand the selection
```

4. Select **Expand the selection**.
5. Click **Sort**.

### ⚠️ Important

Always expand the selection when your data contains multiple related columns.

This keeps the data in each row together.

---

# 4️⃣ ⚙️ Advanced Sort

For more control, use:

```text
Data → Sort
```

The Sort dialog box allows you to select:

### 🔹 Sort By

Choose the column you want to sort.

Example:

```text
Sort by → Name
```

### 🔹 Sort On

You can sort based on:

* 📝 Cell Values
* 🎨 Cell Color
* 🔤 Font Color
* 🔲 Conditional Formatting Icon

### 🔹 Order

Depending on the selected data type, you can choose:

* A to Z
* Z to A
* Smallest to Largest
* Largest to Smallest
* Custom List

---

# 5️⃣ ➕ Multiple-Level Sorting

Excel allows you to add multiple sorting levels.

For example:

```text
Sort by → Department
Then by → Name
Then by → Salary
```

Use:

```text
Add Level
```

This allows Excel to sort the data using multiple conditions.

---

# 6️⃣ ↕️ Sort Orientation

Excel provides two main sort orientations.

### 1. ⬇️ Sort Top to Bottom

This is the normal sorting method.

Data is sorted **down the columns**.

Example:

```text
A
B
C
D
```

### 2. ➡️ Sort Left to Right

This sorts data **across rows**.

Go to:

```text
Data → Sort → Options → Sort left to right
```

Then select the row you want to sort.

---

# 7️⃣ 🎨 Sorting by Color

Excel can also sort data based on formatting.

You can sort by:

* 🎨 Cell Color
* 🔤 Font Color
* 🔔 Conditional Formatting Icon

Example:

```text
Data → Sort → Sort On → Cell Color
```

Then select the required color and order.
