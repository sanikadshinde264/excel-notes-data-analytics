# 🔍 Filter in Excel

**Filter** in Excel is used to display only the data that meets specific conditions while temporarily hiding the other rows.

---

# 1️⃣ Apply Filter

### 📊 Data Tab

Go to:

```text
Data → Filter
```

### 🏠 Home Tab

Go to:

```text
Home → Sort & Filter → Filter
---

# 2️⃣ 🎨 Filter by Colour

Excel allows you to filter data based on formatting.

You can filter by:

* 🎨 Cell Color
* 🔤 Font Color
* 🔔 Conditional Formatting Icon

### Steps

1. Select the column.
2. Click the filter arrow.
3. Select **Filter by Color**.
4. Choose the required color.

---

# 3️⃣ 🧹 Clear Filter

To remove the filter from a particular column:

```text
Filter Arrow → Clear Filter From [Column Name]
```

To remove all filters:

```text
Data → Clear
```

This clears the applied filter conditions while keeping the Filter feature available.

---

# 4️⃣ 🔤 Text Filters

Text filters are used when a column contains text values.

Go to:

```text
Filter Arrow → Text Filters
```

Available options include:

* 🟰 **Equals**
* ❌ **Does Not Equal**
* 🔎 **Contains**
* 🚫 **Does Not Contain**
* ▶️ **Begins With**
* ◀️ **Ends With**
* ⚙️ **Custom Filter**

### Example

If the Product column contains:

```text
Mouse
Keyboard
Monitor
Mouse Pad
```

Using:

```text
Text Filters → Contains → Mouse
```

will display rows containing **Mouse**.

---

# 5️⃣ 🔢 Number Filters

Number filters are used for columns containing numerical values.

Go to:

```text
Filter Arrow → Number Filters
```

Available options include:

* 🟰 **Equals**
* ❌ **Does Not Equal**
* 🔝 **Greater Than**
* ⬆️ **Greater Than or Equal To**
* 🔽 **Less Than**
* ⬇️ **Less Than or Equal To**
* 🏆 **Top 10**
* 📈 **Above Average**
* 📉 **Below Average**
* ⚙️ **Custom Filter**

### Example

To display values greater than 500:

```text
Number Filters → Greater Than → 500
```

---

# 6️⃣ 📅 Date Filters

Date filters are used when a column contains dates.

Go to:

```text
Filter Arrow → Date Filters
```

Common options include:

* 🟰 **Equals**
* 📅 **Before**
* 📅 **After**
* ↔️ **Between**
* ⚙️ **Custom Filter**

Date filters can also provide options based on:

* Today
* Tomorrow
* Yesterday
* This Week
* Last Week
* Next Week
* This Month
* Last Month
* Next Month
* This Year

# 7️⃣ 🔎 Find and Replace

Excel provides **Find and Replace** to search for specific data and replace it with another value.

### ⌨️ Shortcut Keys

**Find:**

```text
Ctrl + F
```

**Replace:**

```text
Ctrl + H
```

---

## 🔍 Find

To search for specific data:

```text
Ctrl + F
```

Enter the value you want to find.

---

## 🔄 Replace

To replace data:

```text
Ctrl + H
```

A dialog box appears with:

```text
Find what:     [value to find]

Replace with:  [new value]
```

### Steps

1. Select the required data or column.
2. Press **Ctrl + H**.
3. Enter the value in **Find what**.
4. Enter the new value in **Replace with**.
5. Click **Replace All**.
6. Click **Close**.

### Example

If you want to replace:

```text
Old → New
```

Enter:

```text
Find what: Old
Replace with: New
```

Then click:

```text
Replace All
```
