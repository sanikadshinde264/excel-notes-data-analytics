# ⌨️ Excel Keyboard Shortcuts

## 📌 Overview

Keyboard shortcuts help me perform common Excel tasks quickly and efficiently. These shortcuts are useful for **data cleaning, data analysis, and working with large datasets**.

## 🧾 Basic Shortcuts

| No. | Action                               | Shortcut           |
| --: | ------------------------------------ | ------------------ |
|   1 | 💾 **Save**                          | `Ctrl + S`         |
|   2 | ↩️ **Undo**                          | `Ctrl + Z`         |
|   3 | ↪️ **Redo**                          | `Ctrl + Y`         |
|   4 | 📄 **Add New Sheet**                 | `Shift + F11`      |
|   5 | ✏️ **Rename Sheet**                  | `Alt + H + O + R`  |
|   6 | 📏 **AutoFit Column Width**          | `Alt + H + O + I`  |
|   7 | ➡️ **Select to the Right**           | `Shift + →`        |
|   8 | ⬇️ **Select Downward**               | `Shift + ↓`        |
|   9 | ⬇️ **Fill Down**                     | `Ctrl + D`         |
|  10 | ➡️ **Fill Right**                    | `Ctrl + R`         |
|  11 | 🔲 **Select Data to the Right**      | `Ctrl + Shift + →` |
|  12 | 🔲 **Select Data Downward**          | `Ctrl + Shift + ↓` |
|  13 | 🎯 **Return to Active Cell**         | `Ctrl + Backspace` |
|  14 | ➡️ **Move to the Right End of Data** | `Ctrl + →`         |
|  15 | ✏️ **Edit Active Cell**              | `F2`               |
